# Manuscript integration

`proposed_methods.tex` and `experimental_setup.tex` describe the current method and
fixed experimental design. `figure_table_includes.tex` contains the complete and
page-limited table/figure interfaces. No performance values are embedded in these
files; the results are generated by the configured experiment.

After both studies finish, run:

```shell
python -m cora_maple export-paper --workspace runs/tep_cv10x5_cleanft_v2_1 --destination paper/generated
```

The export writes `tables/` and `figures/` under `generated/`. Copy those directories
into the manuscript project, or reference them from the surrounding LaTeX source.
The table and plot filenames match `figure_table_includes.tex`. For a six-page
paper use either the complete eleven-entry table or its seven-method alternative
with the separate six-condition pretraining comparison. Detailed values for every
condition remain in the experiment's reports regardless of manuscript selection.

The two Scratch entries have identical settings and paired seeds under the default
common schedule and should not be interpreted as independent experimental evidence.
P/U headers describe CorA-MAPLE pretraining exposure versus test-only conditions,
not the training exposure of every ablation or baseline. All classifier training
is clean-only. Test severity 40/50% exceeds the 30% training ceiling for P conditions.
Sample SD is calculated across ten repetition means, not across independent folds.

The full benchmark is not run by the software test suite. Check the completed
workspace audits before using any generated score in the manuscript. The software
package does not include an IFAC class or bibliography style; use the original
conference template in the manuscript project.
